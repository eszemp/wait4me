Passenger Interface

The passenger interface is intended for passengers and is designed to be used on a smartphone. It works also on bigger screens.

Driver Interface

The driver interface is intended for drivers and is designed to be used on a tablet in landscape mode. It works also on bigger screens.

Delay Impact Analysis

The delay impact analysis provides insights into how delays affect public transportation services and is designed for desktop use.

Demo Video

The demo video shows how Wait4Me works and how the different interfaces interact with each other.
