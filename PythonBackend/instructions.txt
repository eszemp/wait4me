ensure .env file exists and contains all necessary DB configs (see .env.example)

run 'python c:/Workspace/Wait4Me/wait4me/PythonBackend/backend_app.py'
keep this terminal window open, so that the backend is running and listening

run 'ng serve' normally in other terminal window


DEPLOYMENT (SERVER)

setup:

create venv on server:

python3.12 -m venv venv
source venv/bin/activate
pip install waitress

python3 -m pip install -r PythonBackend/requirements_server.txt
(txt created with: pip list --format=freeze > requirements.txt)

start a screen session: 
screen -S run_backend

find name screen -ls
reattach to screen session: screen -r <name of run_backend>
ensure venv is running (otherwise: source venv/bin/activate)
waitress-serve --host=localhost —port=8000 wait4me/PythonBackend/backend_app:backend_app
(exit using ctrl+a, d)


Notes on how to deploy new version:
ng build
Run in wait4me/Wait4Me/dist/Wait4Me/ folder
scp -r ./browser/* w3_wait4meprd@wait4me.ethz.ch:~/htdocs/

Server: git switch main, git pull, ..

if backend_app.py changes restart flask in screen session
