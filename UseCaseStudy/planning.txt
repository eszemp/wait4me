
--- Code Structure ---

01_preprocess_tarif_area -> get one polygon with borders of tarifverbund from tarifverbund shp
02_preprocess_stop_places -> extract stop places in tarif area and keep only necessary attributes
03_calculate_time_series -> per stop: calculate buffer between all arrivals and the next departure (use OJP API) over a typical weekday
04_aggregate_to_final_buffer_score -> per stop: extract one final metric per stop and save items
05_network_analysis -> calculate some network level stats
06_network_visualization -> create network level map and visualization of all stop places and buffer metrics
